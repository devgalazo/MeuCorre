# Moto App Manager

Quero criar um aplicativo completo para controlar meu trabalho com Uber Moto e 99 Moto, usando como referência minha planilha atual. Não quero somente uma planilha com aparência de aplicativo. Quero um aplicativo funcional, fácil de usar pelo celular, que salve meus dados e faça os cálculos automaticamente. Quero que você trabalhe como um desenvolvedor profissional e me ajude a construir esse aplicativo por etapas. Antes de começar a programar, quero que você entenda como eu trabalho e me faça perguntas sobre as funções que preciso. Não invente regras que eu não expliquei. O aplicativo deve ter registro diário dos ganhos de cada aplicativo, quilometragem total percorrida pela moto no dia, incluindo todos os deslocamentos, total de horas online, combustível, alimentação, manutenção e outros gastos, cálculo automático de faturamento, despesas, lucro estimado, lucro por hora e por quilômetro, histórico diário, semanal e mensal, gráficos, relatórios, edição de registros, exportação para Excel e salvamento seguro dos dados. Quero uma interface moderna, simples e rápida para preencher no celular. Não comece criando apenas telas bonitas. Quero que os botões, formulários, cálculos e banco de dados funcionem de verdade. Primeiro, faça as perguntas necessárias para descobrir exatamente como quero o aplicativo. Depois apresente o planejamento, a estrutura das telas e as etapas de desenvolvimento. Só então comece a construir e testar cada parte.
